# Final Project

## Emotion Detector

This is the IBM Skills Network Final Project for building an emotion detection application using Watson NLP.

## Project Name
Final Project

## Features
- Emotion detection using Watson NLP
- Flask web interface
- Unit testing
- Error handling
- Static code analysis with Pylint

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

Open http://127.0.0.1:5000
